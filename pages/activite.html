Activité 1

Quizz de compréhension

Quatre cas pratiques pour vérifier si vous savez identifier quand et comment utiliser une IA, et quel niveau de précision est requis.

Premier cas

À partir d'une trentaine de critères bien définis (la surface habitable, le nombre de chambres, l'emplacement, etc.), on souhaite prédire le prix d'une maison.

Nécessité de l'IA

Précision nécessaire

→ Oui, l'utilisation de l'IA est intéressante : sans elle, il faudrait calculer manuellement l'influence de chaque critère sur le prix — tâche fastidieuse. L'IA va reconnaître les tendances automatiquement pour une estimation plus précise. C'est un modèle de régression (le résultat est un nombre). La précision demandée est élevée mais pas très élevée : une estimation à quelques milliers d'euros près suffit généralement.
1 / 4

Deuxième cas

Calculer le carré de plusieurs nombres entiers.

Nécessité de l'IA

→ Non, l'utilisation de l'IA n'est pas nécessaire ici. La fonction carré n'est pas linéaire : il faudrait énormément de données pour que le modèle fonctionne correctement, alors qu'une simple calculatrice y arrive parfaitement en consommant beaucoup moins de ressources.
2 / 4

Troisième cas

Détecter un cancer du sein grâce à des radiographies.

Nécessité de l'IA

Précision nécessaire

→ Oui, l'IA peut très bien repérer des anomalies aussi petites que des tumeurs sur des radiographies. C'est un problème de Computer Vision. Pour ce modèle, la précision doit être très élevée : un faux négatif (tumeur non détectée) peut avoir des conséquences fatales.
3 / 4

Quatrième cas

Vous êtes dans un pays scandinave et vous ne connaissez pas la langue. Vous voulez savoir ce qu'il y a d'écrit sur un panneau — mais il fait très froid.

Nécessité de l'IA

Précision nécessaire

→ Oui, vous pourriez recopier le texte dans Google Traduction, mais il fait froid — une IA qui traduit automatiquement depuis une photo est bien plus pratique. Cette IA combinerait Computer Vision (lire le texte sur l'image) et LLM (traduire le texte). La précision doit être élevée car une mauvaise traduction pourrait changer complètement le sens du panneau.
4 / 4

Activité 3

Entraînement et utilisation d'une IA

Découvrez comment une IA est entraînée et pourquoi les données sont cruciales, puis programmez un mini-projet utilisant les prédictions de votre modèle.

Partie 1 — Entraînement
01

Aller sur le site

pixees.fr/classcodeiai/app/tuto1/ — puis aller dans la section « Expérimenter ».

02

Suivre les étapes

Si un intervenant fait l'activité avec vous, vous pouvez passer les vidéos — les explications seront données à l'oral.

Partie 2 — Utilisation avec VittaScience
01

Aller sur VittaScience

fr.vittascience.com/ia/images

02

Créer vos catégories (partie Données)

Ajouter des catégories et leur affecter des images. Trois façons d'ajouter des images :

  • Caméra (icône caméra)
  • Catégories existantes (icône 6 carrés)
  • Téléversement depuis votre appareil (icône téléchargement)
03

Entraîner le modèle

Cliquer sur « Entraîner le modèle » dans la section Entraînement. Tester ensuite dans « Aperçu » en téléversant une image de test.

04

Passer à la programmation avec AdaCraft

Une fois satisfait du modèle, cliquer sur le bouton AdaCraft. Les deux blocs indispensables sont :

  • Sélectionner et initialiser le modèle de la mémoire locale du navigateur
  • Lancer la détection de la caméra (ou sur fichier/URL sans caméra)
05

Idées de projets

  • Tri des poubelles — un objet se dirige vers la bonne poubelle selon la photo
  • Voiture autonome — la voiture tourne selon les panneaux détectés
  • Météo — affichage soleil/pluie selon l'image capturée
  • Pierre-feuille-ciseaux — comparer le geste capturé à une variable aléatoire
Activité 4

Programmation d'une IA

Vous allez programmer votre propre IA de classification de chats et de chiens sur Kaggle Notebooks (infrastructure Google). L'entraînement prend quelques minutes au lieu de plusieurs heures grâce au GPU mis à disposition.

Mise en place — Kaggle
01

Créer un compte Kaggle

Rendez-vous sur kaggle.com/code et créez un compte (société acquise par Google).

02

Rechercher le notebook de l'activité

Dans la barre de recherche, tapez ACTIVITE IA LYCEE. Sélectionnez le résultat en majuscules, sans chiffre, avec le logo ESEO.

03

Copier le notebook

Cliquer sur « Copy and Edit » en haut à droite. Votre copie personnelle apparaîtra dans « Your Work ».

04

Configurer la session

Dans le panneau « Session options » (droite de l'écran), configurer :

  • Accelerator : GPU P100
  • Internet : activé (indispensable pour le dataset)

Puis cliquer sur le bouton On/Off en haut à droite pour démarrer la session.

Le code — 8 parties
1

Les librairies

Importer les librairies nécessaires. Si des erreurs apparaissent au premier lancement, relancer la cellule — elles se corrigent automatiquement.

2

Vérification du GPU

Vérifie que le GPU est bien détecté. Si vous voyez GPU not found, vérifiez que GPU P100 est bien sélectionné dans les options de session.

3

Le dataset

Import du jeu de données via tfds.load(). Internet doit être activé. Cette cellule peut prendre quelques minutes.

4

Informations du dataset

Affiche les métadonnées du dataset (nombre d'images, dimensions, etc.).

5 ✏️

Le modèle d'IA — votre partie principale

Créez votre modèle avec Sequential(). Chaque ligne = une couche. Pour améliorer les performances, ajoutez des couches de convolution + pooling et/ou augmentez le nombre de neurones : 

tf.keras.layers.Conv2D(NOMBRE_NEURONES, 3, activation='relu')

⚠️ Ne jamais modifier les dimensions 250×250 présentes dans les sections « Importation du dataset » et « Création du modèle » — le programme de test de fin d'activité s'attend à cette taille.

6

L'entraînement

Lance l'apprentissage. Après chaque epoch s'affichent l'accuracy (proportion d'images correctement prédites) et la loss (erreur du modèle). Objectif : accuracy haute + loss basse. Augmenter le nombre d'epochs si le modèle peut encore progresser sans surapprendre.

7

Sauvegarde du modèle

Enregistre votre IA dans un fichier .keras visible dans le panneau Output (droite). Cliquer sur Refresh si le fichier n'apparaît pas immédiatement. Changer le nom entre chaque sauvegarde pour ne pas écraser la précédente.

8

Affichage des résultats

Graphes détaillés de l'évolution des performances au fil des epochs. Utile pour détecter un surapprentissage.
